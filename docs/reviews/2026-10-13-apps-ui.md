# Adversarial UI review: macOS and iOS apps (2026-10-13)

> Policy update (2026-10-14): pending-message extraction/editing was intentionally removed. Historical Edit references below describe the earlier review, not current supported behavior. Cancel, steering and normal queued delivery remain.

Inputs: apple/ at casm-ng HEAD, plus 62 screenshots from the Mac and the iOS simulator. Some
screenshots predate the code, so findings already fixed in code were dropped.

## Blockers
- **B1. The composer draft is lost when you switch agents.**
  - Where: `Composer.text` and `attachments` are `@State` (Composer.swift:16,19). The ChatModel is
    rebuilt on every selection (AppModel.swift:122–129), and the detail view is `.id`'d to the chat
    (CasmApp.swift:122–123). Half-filled QuestionCard answers (QuestionCard.swift:9–12) are lost too.
  - Fix: keep per-agent drafts in AppModel, persisted to UserDefaults, as Paseo does.
- **B2. Pending messages and usage limits have no UI.**
  - Where: commits a4dc6b8 and cb5dc80 touch no apple/ files. The only trace is a "Queued" notice
    (ChatModel.swift:233).
  - Fix: a pending strip above the composer (cancel ✕, edit, which pulls the message back into the
    composer), and a limit banner with the reset time.

## Major
- **M1. Stale UI while a host is offline.**
  - Where: on disconnect only `state` changes (AppModel.swift:178–186). Agent statuses, permission
    banners and the Working badge stay, and so do the menu bar counts (MenuBar.swift:54–56). The
    send button greys out with no explanation (Composer.swift:45).
  - Fix: dim the agents of offline hosts, add a "<host> offline, reconnecting… Retry" bar in chat,
    and disable answer buttons while offline.
- **M2. AGENTS.md edits are lost on Done or swipe-down, and saves can clobber the file.**
  - Where: Done dismisses even when dirty, with no `interactiveDismissDisabled` (ProjectDetails.swift:48–50).
    `save()` writes with no version check (ProjectDetails.swift:160–167).
  - Fix: confirm when dirty, add `.interactiveDismissDisabled(dirty)`, and check for conflicts.
- **M3. On iPhone you can't queue while the agent works.**
  - Where: while busy, Interrupt is the only button (Composer.swift:227–234), and the soft Return
    key inserts a newline.
  - Fix: show Send when there's text, Stop when it's empty and the agent is busy.
- **M4. Too many busy cues, and the context ring looks like a spinner.**
  - Where: three busy indicators (ChatView.swift:57–61, Composer.swift:117–119,
    ChatView.swift:164–165), and the idle ring (ComposerSupport.swift:197–231) looks like a spinner.
  - Fix: one cue; draw the ring with a filled track or as "24k" text, and hide it below ~50%.
- **M5. Dead Mic and Waveform buttons are always visible** (Composer.swift:121–130). Hide them until voice ships.
- **M6. iOS tap targets and model visibility.**
  - Where: Send and Stop are 26 pt (Composer.swift:232,240). Pickers collapse to bare icons, and
    the iPhone never shows the current model (`navigationSubtitle` is macOS-only, ChatView.swift:52–54).
  - Fix: 44 pt hit areas; show a short model name on iPhone, dropping the effort label first.
- **M7. Return can approve a permission by accident, and Bypass needs no confirmation.**
  - Where: Allow is `.defaultAction` (ChatView.swift:506). Bypass is one tap with no warning tint
    (Composer.swift:555–559, 575).
  - Fix: ⌘Return for Allow, on the first banner only; confirm Bypass and tint the mode chip.
- **M8. Cards answered elsewhere, or whose answer failed, get stuck.**
  - Where: a card is removed only on success (ChatModel.swift:310–318).
  - Fix: treat not-found or already-resolved as removal, and say "Answered elsewhere".

## Minor
- **m1.** A failed send is restored only if the field is empty (Composer.swift:327). Fix: append
  it, or show a failed chip with Retry.
- **m2.** Raw model and mode ids flash before the catalog loads (Composer.swift:425,503).
- **m3.** "/" gives no loading or error feedback (Composer.swift:294–296, ChatModel.swift:251–255).
- **m4.** Status wording varies: "Needs you" / "Waiting for you" / "waiting". Pick one term.
- **m5.** The New Agent sheet shows raw provider and effort ids (Sheets.swift:268,278). Reuse the
  composer's display names.
- **m6.** Question "Dismiss" has the same weight as Submit, with no undo. Return and arrow keys
  don't work in the card on macOS.
- **m7.** Tool output is cut at 4,000 characters with no Show all or Copy (ChatView.swift:453).
- **m8.** A permanent "+" on every iOS project row (SidebarView.swift:232–235). Use swipe actions
  or the context menu.
- **m9.** Host status is a colour-only dot. Add an accessibility label (SidebarView.swift:101–136).
- **m10.** Symbol effects ignore Reduce Motion (ChatView.swift:562,575; Composer.swift:404).
  Low confidence.
- **m11.** The iOS keyboard collapses after every send (Composer.swift:321–323).

## Keep
- The shared 900 pt composer and transcript column.
- Restrained transcript rows: tool rows, collapsed Thinking, wrapping tables, and the searchable mode picker.
- Careful destructive-action copy, and good macOS keyboard coverage.
